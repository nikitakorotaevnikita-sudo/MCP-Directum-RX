# Навык «Название по-русски»

Одним абзацем: какую работу пользователя заменяет навык и что получает пользователь в итоге. Кто принимает решение
(агент только подсказывает или делает сам).

## Когда использовать

- Пользователь просит …
- Нужно …
- **Не** использовать, когда … (для этого есть навык `другой-навык`).

## Данные

Какие инструменты вызвать и в каком порядке. Пишите конкретно: тул и параметры.

1. `tool_name(param=…)` — что берём. Ответ сохрани в файл как есть (`данные.json`).
2. `another_tool(id=…)` — если нужно ещё …
3. Если данных нет — скажи пользователю прямо, чего не хватает. Ничего не додумывай.

## Скрипт

```bash
python scripts/skill_script.py данные.json --format md
python scripts/skill_script.py данные.json --only-overdue      # пример параметра
cat данные.json | python scripts/skill_script.py - --format json
```

Что считает скрипт и что возвращает (поля результата).

| Код выхода | Значение | Что делать |
|---|---|---|
| 0 | Успех | Работай с результатом, предупреждения (`warnings`) передай пользователю |
| 2 | Ошибка входных данных | Сообщение в stderr — исправь вызов или запроси данные заново |
| 1 | Непредвиденная ошибка | Сообщи пользователю текст ошибки |

## Как отвечать

1. Сначала вывод одной строкой: …
2. Потом детали: таблица или список, у каждой записи — ссылка на карточку (`url`).
3. Что пользователю сделать дальше.

## Правила

- Числа, даты, ФИО и ссылки — только из ответов инструментов и вывода скрипта.
- Персональные данные граждан (адрес, телефон, email) не выводить.
- Решение принимает человек; навык показывает основания.

Пример входа — `examples/example_input.json`.
