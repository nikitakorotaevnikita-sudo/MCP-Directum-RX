# Карты регионов для навыка og-heatmap

Готовые геопакеты районов для тепловой карты обращений (навык `og-heatmap`). В навык включены только Владимирская и
Челябинская области. Остальные регионы берите отсюда и добавляйте в навык вручную.

**Всего:** 86 файлов, 2596 районов, 3 МБ.

## Как добавить регион в навык

1. Скопируйте нужный файл `<код>.json` в папку `regions/` навыка. Есть два способа:
   - в репозитории — в `docs/usecases/skills/og-heatmap/regions/`, затем пересоберите архив:
     `python docs/usecases/skills/package_skills.py og-heatmap` и скопируйте `dist/og-heatmap.zip` в `docs/skills/`;
   - в готовом архиве — распакуйте `og-heatmap.zip`, положите файл в `regions/` и упакуйте обратно
     (`SKILL.md` должен остаться в корне архива).
2. Перезагрузите навык в LibreChat или Cowork и начните новый чат.

Регион карта определяет сама по полю `region` в ответе тула. Если не определила, агент вызывает скрипт с
`--region <код>`.

## Формат файла

Тот же, что у `regions/vladimir.json` в навыке:

```
code, region, source, viewBox, areas: [key, name, kind, aliases, path, cx, cy, pts]
```

- `kind` — вид района: «муниципальный район», «муниципальный округ» или «городской округ».
- `aliases` — как район может называться в RX: «м.р-н. …», «г. …», «г.о. город …». Названия из RX вида
  «м.р-н. Муромский», «г.о. город Ковров», «г. Тобольск» сопоставляются автоматически, это проверено по всем
  файлам. Если в RX район называется иначе, допишите его название в `aliases` нужного района.
- `path` — SVG-контур района, уже упрощённый: не больше 4000 точек на регион.

## Свой регион или обновление границ

Скрипт навыка `scripts/geojson_to_region.py` собирает такой файл из любого GeoJSON с районами:

```
python scripts/geojson_to_region.py районы.geojson --code vladimir --region "Владимирская область"
```

## Источник и ограничения

- **Источник границ.** OpenStreetMap, лицензия ODbL. На карте всегда указывается «© участники OpenStreetMap».
- **Выгрузка.** Сборка — [timurkanaz/Russia_geojson_OSM](https://github.com/timurkanaz/Russia_geojson_OSM),
  уровень admin_level=6. Владимирская и Челябинская области взяты из навыка: они сверены со справочником RX стенда
  и с OSM 2025 года.
- **Возраст границ.** Выгрузка сделана до части муниципальных реформ: где районы преобразованы в муниципальные
  округа, названия могут отличаться от RX. Такие районы карта перечисляет в примечании, их нужно дописать в
  `aliases`.
- **Нет данных** по ДНР, ЛНР, Запорожской и Херсонской областям.
- **Города.** Москва (`moscow-city`), Санкт-Петербург (`saint-petersburg`) и Севастополь (`sevastopol`) разбиты на
  внутригородские районы и муниципальные образования. Отдельно есть Казань по районам города (`kazan-city`).
