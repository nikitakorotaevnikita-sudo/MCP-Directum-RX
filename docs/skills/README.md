# Собранные навыки агентов mcpOGV

Готовые к загрузке архивы навыков: по `ИМЯ.zip` и `ИМЯ.skill` на каждый (содержимое одинаковое, `SKILL.md` — в
корне архива). Исходники — [`docs/usecases/skills/<имя>/`](../usecases/skills/), описание сервера и настройка
агентов — [`docs/mcp-ogv-overview.md`](../mcp-ogv-overview.md), системные промпты — [`docs/prompts/`](../prompts/).

Как создать новый навык или агента —
[`Инструкция по разработке агентов и навыков Cowork ОГВ.md`](<../skills-dev-kit/Инструкция по разработке агентов и навыков Cowork ОГВ.md>), шаблоны — в той же папке
[`docs/skills-dev-kit/`](../skills-dev-kit/).

Загрузка в LibreChat / Cowork: раздел навыков → загрузить `.zip` (или `.skill`) → подключить навык к агенту. Скрипты
навыков выполняются в среде выполнения кода (Python 3.10+).

## Агенты: что подключить

| Агент | Системный промпт | MCP-серверы | Навыки |
|---|---|---|---|
| Главный агент ОГВ | [`main-agent.md`](../prompts/main-agent.md) (компактный — [`main-agent-compact.md`](../prompts/main-agent-compact.md)) | mcpOGV | `pdf-report`, `excel-report`, `pptx-creator`, `pdf-read`, `xlsx-read`, `doc-version` |
| Правовой отдел — НПА | [`legal-acts-agent.md`](../prompts/legal-acts-agent.md) | mcpOGV, «Гарант» | `pa-*`, `doc-version`, `pdf-report`, `excel-report` |
| Обращения граждан — УРОГ | [`citizen-requests-agent.md`](../prompts/citizen-requests-agent.md) | mcpOGV, «Гарант» | `og-*`, `pdf-report`, `excel-report` |
| Контроль исполнения | [`control-agent.md`](../prompts/control-agent.md) | mcpOGV | `kd-*`, `pdf-report`, `excel-report`, `pdf-read` |
| Классификатор обращений; Ответы на обращения граждан | репозиторий Class-OG-Final: `cowork/agent-instruction.md`, `cowork/answer-agent/agent-instruction.md` | mcpOGV (в т. ч. `classifier_search`, `classifier_get`), mcp-pravo | их навыки — в `docs/skills/` репозитория Class-OG-Final; отсюда берут `og-repeat`, `og-letters`, `og-answer-review` |

**MCP «Гарант» (с ноября 2026):** `search_documents`, `get_document`, `get_document_block`, `find_fragments`,
`check_document`, `get_limits` — вместо прежних `garant_*`. Редакций, судебной практики, новостей и выгрузки в файлы
в нём нет. Назначение инструментов в промптах и навыках выведено из названий — сверить с их описаниями.

## Общие навыки

| Навык | Назначение | Зависимости |
|---|---|---|
| `pdf-report` | PDF-отчёт из JSON-спецификации (кириллица, таблицы, ссылки) | reportlab ≥ 4.0 |
| `excel-report` | Excel-выгрузка: типизированные колонки, итоги, подсветка | openpyxl ≥ 3.1 |
| `pptx-creator` | Презентация .pptx — ровно 5 слайдов (титул, содержание, суть, данные, выводы), 16:9, Calibri; данные только из инструментов | python-pptx ≥ 1.0 |
| `pdf-read` | Текст PDF с текстовым слоем, поиск страниц-сканов | pypdf ≥ 4.0 |
| `xlsx-read` | Чтение и анализ одной или нескольких таблиц Excel/CSV: отбор, свод, склейка, сверка по ключу | openpyxl ≥ 3.1 |
| `doc-version` | Новая версия документа в RX автономно, без подтверждения пользователя (нужен mcpOGV с записью) | — |

## Правовой отдел (НПА) — агент «Правовой отдел — НПА»

| Навык | Назначение |
|---|---|
| `pa-route` | Маршрут проекта правового акта: этап, что дальше, кто следующий |
| `pa-legal-basis` | Правовые основания по ГАРАНТу: действуют ли акты, верны ли реквизиты, совпадает ли норма с действующим текстом |
| `pa-normcontrol` | Предварительный нормоконтроль и лингвистическая проверка |
| `pa-anticorruption` | Признаки коррупциогенных факторов (Методика № 96 — текст из ГАРАНТа) |
| `pa-orv` | Нужна ли ОРВ, материалы к обсуждениям, заключение |
| `pa-compare` | Сравнение редакций по пунктам; проекта — с действующей нормой из ГАРАНТа |
| `pa-conclusions` | Черновики заключений, замечаний, сопроводительных писем; создание в RX |

Юзкейсы:

| Запрос пользователя | Навык | Что делает агент |
|---|---|---|
| «Где застряли наши проекты?», «что с проектом 26-044?» | `pa-route` | `list_legal_acts_on_approval` / `get_legal_act`: этап, у кого, сколько ждёт, что дальше |
| «Проверь ссылки на законы», «действуют ли основания?» | `pa-legal-basis` | текст проекта → ссылки (`extract_legal_refs.py`, `check_document`) → по каждой: `search_documents`, `get_document`, `get_document_block` |
| «Что изменилось в законе, на который ссылается проект?» | `pa-legal-basis` + `pa-compare` | сверка процитированной нормы с действующим текстом (истории редакций в ГАРАНТе нет) |
| «Проверь проект перед согласованием» | `pa-normcontrol` → `pa-legal-basis` → `pa-anticorruption` → `pa-orv` | единый ответ: замечания по форме, основаниям, факторам, нужна ли ОРВ |
| «Сравни проект и принятый акт» | `pa-compare` | `get_legal_act` → `adopted_act` → `compare_texts.py` |
| «Подготовь заключение / замечания / сопроводительное» | `pa-conclusions` | черновик по шаблону; нормы — только из ГАРАНТа |
| «Внеси правки в проект», «загрузи исправленный файл» | `doc-version` | новая версия документа в RX без вопроса «Создать?» |
| «Подписаны, но не опубликованы», «справка руководителю по НПА» | — / `pdf-report` | `find_legal_acts` по этапам, таблица со ссылками, файл |

## Обращения граждан (УРОГ) — агент «Обращения граждан»

| Навык | Назначение |
|---|---|

| `og-terms` | Сроки 59-ФЗ и просрочка |

| `og-letters` | Черновики писем, шаблоны RX, создание писем организациям; нормы в ответе — только из ГАРАНТа, иначе `[норма]` |
| `og-control` | Сводка сроков и статистика по ТОТК |
| `og-answer-review` | Качество ответов постфактум по стандарту навыка (`standard/standard.json` внутри архива) |
| `og-heatmap` | Тепловая карта обращений по районам региона: HTML-файл или React-артефакт; геопакеты Владимирской и Челябинской областей (OSM, ODbL) |

Юзкейсы:

| Запрос пользователя | Навык | Что делает агент |
|---|---|---|
| «Что с обращением 13-ОГ?», звонок гражданина | `og-route` | `get_citizen_request_status`: состояние, срок, исполнитель, есть ли ответ |
| «Проверь карточку», «можно ли отказать?», анонимные и коллективные | `og-registration` | чек-лист карточки и результат задания; решение — за уполномоченным лицом |
| «Что горит?», «соблюдены ли сроки?», «можно ли продлить?» | `og-terms`, `og-control` | `list_citizen_requests_due` → `check_terms.py` / `due_digest.py` |
| «Это не наша компетенция, куда перенаправить?» | `og-redirect` | порядок в RX, 7 дней; полномочия — `search_documents`, `find_fragments` |
| «Писал ли раньше?», «это повторное?» | `og-repeat` | история заявителя → `find_repeats.py` |
| «Подготовь ответ / уведомление о продлении / запрос в ведомство» | `og-letters` | черновик по шаблону, ответ на каждый вопрос, нормы из ГАРАНТа (`find_fragments`, `get_document_block`), проверка `check_document` и `check_letter.py` |
| «На какой закон сослаться в ответе?» | — | `find_fragments` → `get_document` → `get_document_block`: норма с реквизитами |
| «Есть ли ответ?», «что приложено?» | — | `get_document_relations` по обращению |
| «Проверь качество ответов за месяц», «есть ли отписки?» | `og-answer-review` | `list_citizen_request_answers` → `review_answers.py` |
| «Покажи на карте, где больше обращений», «в каких районах просрочки» | `og-heatmap` | `get_citizen_requests_by_territory` → `build_heatmap.py`: картограмма по районам, только агрегаты |
| «Справка руководителю», «статистика по тематикам» | `og-control` + `pdf-report` / `excel-report` | сроки, ТОТК, дисциплина — файл |

## Главный агент ОГВ

Отвечает на разовые вопросы сам и делегирует многошаговые задачи профильным агентам.

| Запрос пользователя | Что делает агент |
|---|---|
| «Что у меня в работе?», «что просрочено?» | `list_my_assignments`, `list_action_items` |
| «Кто в отделе срывает сроки?» | `get_department_discipline` → `list_employee_action_items` |
| «Найди письмо из Минфина про дороги» | `find_documents`, `find_documents_by_content` |
| «О чём этот документ?», «что с ним связано?» | `get_document_text`, `get_document_relations` |
| «Что сказано в документах про…?» | `ask_documents` |
| «Создай письмо / поручение / задачу» | тулы записи в два шага: предпросмотр → «да» → создание |
| Обращения, НПА, контроль — из нескольких шагов | передаёт агенту «Обращения граждан», «Правовой отдел — НПА» или «Контроль исполнения» |

| «Прочитай присланный PDF» | `pdf-read`: текст по страницам, поиск сканов |

## Запросы из процессов RX

Блок процесса RX обращается к агенту по протоколу OpenAI; агент создаёт документы тулами mcpOGV с `task_id` задачи
процесса: документ прикладывается к задаче, «Подготовил» — автор задачи. Учётка и права — два варианта (личная учётка
пользователя / служебная «от имени»): [`docs/rx-process-cowork-on-behalf-requirements.md`](../rx-process-cowork-on-behalf-requirements.md).

## Обновление

Архивы пересобираются из исходников и копируются сюда:

```bash
python docs/usecases/skills/package_skills.py
cp docs/usecases/skills/dist/*.zip docs/usecases/skills/dist/*.skill docs/skills/
```

Сборка воспроизводимая: одинаковые исходники дают побайтно одинаковые архивы. После обновления навыка в платформе —
перезагрузить архив, начать новый чат.
