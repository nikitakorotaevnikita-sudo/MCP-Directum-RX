# Собранные навыки агентов mcpOGV

Готовые к загрузке архивы навыков: по `ИМЯ.zip` и `ИМЯ.skill` на каждый (содержимое одинаковое, `SKILL.md` — в
корне архива). Исходники — `docs/usecases/skills/<имя>/`, описание сервера и рекомендуемая настройка агентов —
`docs/mcp-ogv-overview.md`.

Загрузка в LibreChat: раздел навыков → загрузить `.zip` (или `.skill`) → подключить навык к агенту. Скрипты навыков
выполняются в среде выполнения кода LibreChat (Python 3.10+).

## Общие

| Навык | Назначение | Зависимости |
|---|---|---|
| `pdf-report` | PDF-отчёт из JSON-спецификации (кириллица, таблицы, ссылки) | reportlab ≥ 4.0 |
| `excel-report` | Excel-выгрузка: типизированные колонки, итоги, подсветка | openpyxl ≥ 3.1 |
| `pdf-read` | Текст PDF с текстовым слоем, поиск страниц-сканов | pypdf ≥ 4.0 |

## Правовой отдел (НПА) — агент «Правовой отдел — НПА»

| Навык | Назначение |
|---|---|
| `pa-route` | Маршрут проекта правового акта: этап, что дальше, кто следующий |
| `pa-legal-basis` | Правовые основания по ГАРАНТу: действуют ли, редакции, изменения, практика |
| `pa-normcontrol` | Предварительный нормоконтроль и лингвистическая проверка |
| `pa-anticorruption` | Признаки коррупциогенных факторов (Методика № 96) |
| `pa-orv` | Нужна ли ОРВ, материалы к обсуждениям, заключение |
| `pa-compare` | Сравнение редакций по пунктам |
| `pa-conclusions` | Черновики заключений, замечаний, сопроводительных писем; создание в RX |

## Обращения граждан (УРОГ) — агент «Обращения граждан»

| Навык | Назначение |
|---|---|
| `og-route` | Маршрут обращения: этап, у кого, что дальше |
| `og-registration` | Проверка карточки и результат регистрации |
| `og-terms` | Сроки 59-ФЗ и просрочка |
| `og-redirect` | Направление по компетенции |
| `og-repeat` | Повторные обращения и история ответов |
| `og-letters` | Черновики писем, шаблоны RX, создание писем организациям |
| `og-control` | Сводка сроков и статистика по ТОТК |
| `og-answer-review` | Качество ответов постфактум по стандарту навыка (`standard/standard.json` внутри архива) |

## Контроль исполнения — агент «Контроль исполнения»

| Навык | Назначение |
|---|---|
| `kd-monitor` | Утренняя сводка с прогнозом срыва |
| `kd-dossier` | Досье поручения: кто держит, переносы, приёмка, запросы отчёта |
| `kd-close` | Готовность к снятию с контроля |
| `kd-resolution` | Проект резолюции по истории руководителя, выдача пакетом |

## Обновление

Архивы пересобираются из исходников и копируются сюда:

```bash
python docs/usecases/skills/package_skills.py
cp docs/usecases/skills/dist/*.zip docs/usecases/skills/dist/*.skill docs/skills/
```

Сборка воспроизводимая: одинаковые исходники дают побайтно одинаковые архивы.
