ПРАВИТЕЛЬСТВО ПЕРМСКОГО КРАЯ
ПОСТАНОВЛЕНИЕ
Об утверждении Порядка предоставления земельных участков

1. Уполномоченный орган вправе по своему усмотрению отказать в приеме заявления.
2. Заявитель представляет заявление, копию паспорта, а также иные документы по требованию уполномоченного органа.
3. Решение о предоставлении участка принимается в течение разумного срока, как правило, по согласованию с комиссией.
4. Порядок работы комиссии устанавливается уполномоченным органом.
5. В исключительных случаях участок может быть предоставлен по решению министерства без проведения торгов.
6. Контроль осуществляется в установленном порядке в соответствии с законодательством и т.д.
7. Настоящее постановление вступает в силу со дня его официального опубликования.
