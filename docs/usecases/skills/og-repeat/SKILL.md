# Навык «Повторные обращения»

Ты помогаешь понять, повторное ли обращение, и собрать историю переписки с заявителем. Совпадения ищет скрипт;
ты проверяешь их по текстам и объясняешь.

По решению Directum RX: повторное обращение связывается с исходным и рассматривается заново тем же порядком.
Регистратор нажимает «Заполнить из обращения» — переносятся вид, дело, вопросы, подвопросы, соцположение, льготы
и ставится флажок **«Повторное»**. «Поиск → Обращения заявителя» показывает обращения за последние полгода.
Период повторности задаётся в настройках организации.

## Данные

1. `get_citizen_request_status(applicant="ФИО", limit=20)` — обращения заявителя (с вопросами, кодами ТОТК,
   ответами). Если ФИО частое — уточни у пользователя номер текущего обращения и сверь по нему.
2. Ответ инструмента сохрани в файл как есть и передай скрипту.
3. Что отвечали — `get_document_text(answer_letter.id)` по найденным ответам.

## Скрипт

```bash
python scripts/find_repeats.py заявитель.json --format md
python scripts/find_repeats.py заявитель.json --period-days 365 --answered-threshold 2
```

- `--period-days` — период повторности (по умолчанию 180 дней; возьми из настроек организации, если пользователь
  их назвал);
- `--answered-threshold` — сколько ранее **отвеченных** обращений по тому же вопросу дают повод проверить ст. 11
  (по умолчанию 2 — «неоднократно»).

Совпадение вопросов — по коду ТОТК, а без кода — по названию вопроса; ФИО сравнивается без учёта регистра,
пробелов и «ё/е». Результат: `repeat_found`, `earlier` (предыдущие обращения, общие вопросы, дней назад),
`shared_questions` (сколько раньше было и сколько отвечено), `flag_mismatch` (расходится с флажком «Повторное»),
`article_11_check`, `notes`. Коды выхода: 0 / 2 (плохой вход) / 1.

## Как излагать результат

1. Итог: «Повторное: да / нет. Раньше по вопросу … — N обращений, отвечено M».
2. История — таблица «Обращение (ссылка) — дата — вопросы — ответ (ссылка на письмо)», по датам.
3. Кратко, что отвечали (по текстам писем) — чтобы новый ответ не противоречил прежним.
4. Расхождение с флажком — подскажи регистратору: отметить «Повторное» («Заполнить из обращения») или снять.
5. Если `article_11_check` — только тогда упомяни ст. 11: руководитель (уполномоченное лицо) **вправе** принять
   решение о безосновательности очередного обращения и прекращении переписки, если в нём нет новых доводов и
   ранее давались письменные ответы по существу; заявитель уведомляется. Решение принимает не ассистент; уточни
   у юриста.

## Правила

- Совпадение кода — не доказательство повторности: сравни суть по текстам (новые доводы = не повторное по смыслу).
- Не выводи в сводках контакты заявителя и не сохраняй историю заявителя в долговременную память.
- Если выборка обрезана (заявитель писал больше, чем вернул инструмент) — скажи об этом.
