# Навык «Чтение и анализ таблиц Excel»

Скрипт `scripts/read_tables.py` читает таблицы из файлов `.xlsx`, `.xlsm`, `.csv` и отвечает на вопросы о них
числами, посчитанными по данным файла. Выгрузки из Directum RX, 1С и отчёты «для печати» обычно не являются
аккуратными таблицами. Скрипт сам приводит их к таблице и сообщает, что именно сделал.

## Когда использовать

- Пользователь приложил к чату один или несколько Excel- или CSV-файлов. Сюда же относится вопрос по таблице, которую
  уже выгрузили из RX.
- Нужно посчитать, сгруппировать или отфильтровать данные, сравнить две версии таблицы, собрать несколько таблиц в
  одну.
- Результат нужен в Excel. Тогда возьми свод отсюда (`--format xlsx-spec`) и передай его навыку `excel-report`.
- Документ из Directum RX сначала скачай в файл: `get_doc_body_base64` → декодировать base64 → сохранить `.xlsx`.

**Числа в ответе бери только из вывода скрипта.** Не считай «в уме» и не пересказывай таблицу по первым строкам.

## Как вызвать

```bash
python scripts/read_tables.py inspect отчёт.xlsx                 # что в файле: листы, где таблица, колонки, примеры
python scripts/read_tables.py profile отчёт.xlsx                 # колонки: заполненность, значения, суммы, ошибки
python scripts/read_tables.py read отчёт.xlsx --limit 20         # строки
python scripts/read_tables.py query отчёт.xlsx --where "Статус = Просрочено" --select "№,Поручение,Срок"
python scripts/read_tables.py query отчёт.xlsx --group-by Исполнитель --agg count --agg sum:Сумма --share
python scripts/read_tables.py combine янв.xlsx фев.xlsx мар.xlsx --out все.csv
python scripts/read_tables.py diff октябрь.xlsx ноябрь.xlsx --key №
python scripts/read_tables.py join поручения.xlsx "справочник.xlsx::Сотрудники" --key Исполнитель --columns Подразделение
```

**Источник** — путь к файлу или `файл::Лист`, где лист задаётся именем или номером с 1. Без указания листа берётся
первый видимый лист с данными. Если в файле есть другие листы, скрипт об этом предупредит. `--all-sheets` берёт все
видимые листы и склеивает их.

**Общие параметры:**
- `--format` — `json` (по умолчанию у `read`, `query`, `combine`, `join`), `md` (по умолчанию у `inspect`,
  `profile`, `diff`), `csv`, `xlsx-spec`;
- `--out файл` — записать результат в файл; в stdout выводится путь;
- `--limit`, `--offset` — вывод по частям. Без `--out` выводится до 100 строк, с `--out` — все;
- `--header-row N` — шапка в строке N (если автоопределение ошиблось); `--no-header` — шапки нет;
- `--range A5:H200` — читать только этот диапазон;
- `--keep-totals` — оставить строки «Итого» в данных; `--skip-hidden` — исключить скрытые строки;
- `--max-rows` — предел строк на лист, по умолчанию 100 000.

**Условия `--where`** (несколько `--where` — это «И»):

| Пример | Смысл |
|---|---|
| `"Сумма > 1000"`, `>=`, `<`, `<=`, `=`, `!=` | Сравнение. Числа — как числа, даты — как даты (`01.11.2026` или `2026-11-01`), текст — без учёта регистра и «ё» |
| `"Тема ~ дорог"`, `"Тема !~ дорог"` | Содержит / не содержит |
| `"Статус in Новый\|В работе"`, `not in` | Одно из значений |
| `"Срок is empty"`, `"Срок is not empty"` | Пусто / заполнено |

**Свод:** `--group-by` — колонки через запятую. `--agg` — показатели: `count`, `count:Кол` (заполненных),
`sum:Кол`, `avg:`, `min:`, `max:`, `median:`, `nunique:`. `--share` добавляет долю первого показателя в процентах.
`--sort "Колонка:desc"` задаёт сортировку; по умолчанию свод сортируется по первому показателю по убыванию.

**Имена колонок:** точное имя, без учёта регистра или уникальная часть имени (`План` → «Сумма, руб. / План»).
Для одной таблицы можно указать букву (`B`). Если имя подходит к нескольким колонкам, скрипт ответит ошибкой и
перечислит подходящие.

| Код выхода | Значение | Что делать |
|---|---|---|
| 0 | Успех | Работай с результатом. Предупреждения (`warnings`) передай пользователю |
| 2 | Плохой вход: нет файла, `.xls` или пароль, нет листа или колонки, ошибка в условии | Сообщение в stderr — исправь вызов (имя колонки возьми из `inspect`) или попроси у пользователя другой файл |
| 1 | Непредвиденная ошибка или не установлен openpyxl | Сообщи текст ошибки. При «не установлен openpyxl» — `pip install -r requirements.txt` |

## Что скрипт делает с «грязным» листом

1. **Шапка.** Ищет строку заголовков в первых 30 строках и пропускает над ней название отчёта и «по состоянию
   на…». Шапку в две строки с объединёнными ячейками склеивает: «Сумма, руб. / План». Строку с номерами колонок
   (1, 2, 3…) под шапкой пропускает.
2. **Объединённые ячейки.** Значение объединённой ячейки копируется во все её ячейки, поэтому подразделение,
   объединённое на несколько строк, есть у каждой строки.
3. **Итоги.** Строки, начинающиеся с «Итого», «Итог», «Всего», «Total», не попадают в данные. `profile` сверяет
   с последней из них суммы колонок (`totals_check`).
4. **Разделы.** Одиночная строка вроде «Отдел ЖКХ», за которой идут данные, становится колонкой «Раздел».
5. **Подписи** под таблицей («Исполнитель: …») не попадают в данные.
6. **Значения:**
   - «1 234,50», «12,5 %», «300 ₽» распознаются как числа; «01.11.2026» и ISO-даты — как даты (в выводе
     `ГГГГ-ММ-ДД`);
   - коды с ведущим нулём, ИНН, СНИЛС и телефоны остаются текстом;
   - единичные «н/д», «—» в числовой колонке остаются как есть, в расчётах не участвуют, о них есть предупреждение.
7. **Скрытое.** Скрытые листы не берутся по умолчанию. Скрытые строки и колонки берутся, о них есть предупреждение.
8. **Формулы без сохранённых значений.** Такое бывает, если файл собран программой, а не Excel. Эти ячейки читаются
   пустыми — `inspect` об этом сообщит.

## Порядок работы

1. **Сначала `inspect`.** Посмотри, где таблица, какие колонки и их типы, что исключено. Если шапка определилась
   неверно, повтори с `--header-row` или `--range`.
2. **Обзор таблицы — `profile`:**
   - пустые колонки, «не те» значения, диапазоны дат, суммы;
   - сверка с итоговой строкой: если суммы не совпали, скажи об этом пользователю — в файле ошибка или скрытые
     строки.
3. **Вопрос пользователя — `query`.** Одно условие — один вызов. Длинные списки выводи частями через `--limit`.
4. **Несколько файлов:**
   - одинаковые таблицы (месяцы, подразделения) — `combine` или `query` по всем сразу. Колонки сопоставляются по
     имени, добавляются колонки «Файл» и «Лист»; если в каком-то файле колонки нет, скрипт предупредит;
   - две версии одной таблицы — `diff --key`. Ключ — колонка с уникальным значением: номер, рег. номер, ИНН,
     табельный номер. Повторы ключа скрипт перечислит;
   - таблица и справочник — `join`.
5. **Результат в Excel:** `--format xlsx-spec --out spec.json` → навык `excel-report`.

## Как отвечать пользователю

- Начинай с ответа на вопрос: число, список, вывод. Потом коротко укажи, по каким строкам считал: «по 6 строкам
  листа „Поручения“, без строк „Итого“».
- Передай предупреждения, которые влияют на ответ:
  - что исключено (итоги, подписи, скрытые строки);
  - «не те» значения;
  - другие листы;
  - несовпадение с итоговой строкой.
- Если взят не тот лист или не та шапка, скажи об этом и повтори вызов с нужными параметрами.
- Таблицу в ответе давай короткой: до 20 строк. Полный результат — файлом (`--out` или через `excel-report`).
- В сверке называй по ключу, что добавилось, удалилось и изменилось — «было → стало».

## Правила

- Не выдумывай числа и строки, которых нет в выводе скрипта. Не экстраполируй с первых строк на всю таблицу.
- Отвечай про таблицу, которую скрипт прочитал. Если пользователь видит в Excel другое, проверь лист, шапку и
  скрытые строки.
- Не повторяй без нужды персональные данные из таблиц: ФИО с телефонами, паспорта, адреса, СНИЛС.
- `.xls`, `.xlsb`, `.ods` и файлы с паролем не читаются. Попроси пересохранить файл как `.xlsx` без пароля.

Пример: `examples/report_oct.xlsx` («грязный» отчёт — заголовок, шапка в две строки, разделы, итоги, подпись,
скрытая строка и лист) и `examples/report_nov.xlsx` (та же таблица месяцем позже — для `diff --key №`).
Пересобрать примеры — `examples/make_example.py`.
