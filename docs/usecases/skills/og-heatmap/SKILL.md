# Навык «Тепловая карта обращений по районам»

Ты показываешь, где в регионе больше обращений или просрочек — картой муниципальных районов, а не таблицей.
Цифры даёт тул mcpOGV, карту рисует скрипт. Ты не рисуешь карту сам и не пересчитываешь числа.

## Когда использовать

- «Покажи обращения на карте», «тепловая карта по районам», «где больше всего обращений».
- «В каких районах просрочки», «сравни районы», «карта по теме ЖКХ за квартал».
- **Не** для списка конкретных обращений: для этого есть `list_citizen_requests_due` и `og-control`. Без карты, просто
  цифрами по районам, отвечай таблицей из того же тула.

## Данные

1. `get_citizen_requests_by_territory(region=…, date_from=…, date_to=…, classifier_code=…)`:
   - `region` — часть названия региона («Владимирская»);
   - период — если не назван, текущий год (скажи об этом);
   - код ТОТК — если просят по теме (найти: `search_citizen_request_classifier`).
2. Ответ тула сохрани в файл **как есть** (`territory.json`).
3. Если `areas` пуст — карту не строй, скажи, что у обращений за период не указан район или город.

## Скрипт

```bash
python scripts/build_heatmap.py territory.json --out /mnt/data/карта-обращений.html
python scripts/build_heatmap.py territory.json --metric overdue --out /mnt/data/просрочки-по-районам.html
python scripts/build_heatmap.py territory.json --format jsx      # React-компонент для артефакта
```

- `--metric` — что красить при открытии: `requests` (обращения, по умолчанию), `overdue` (просрочено), `questions`
  (вопросы). На карте есть вкладки, пользователь переключит сам.
- `--region` — геопакет: `vladimir`, `chelyabinsk`. Обычно не нужен: регион определяется по данным.
- `--format html` (по умолчанию) — самодостаточный файл: открывается в браузере без интернета. `--format jsx` —
  компонент для артефакта `application/vnd.react`: выведи его целиком, не меняя данные и пути.
- `--title` — свой заголовок.

| Код выхода | Значение | Что делать |
|---|---|---|
| 0 | Успех | С `--out` в stdout — путь к файлу; без `--out` — сам HTML / JSX |
| 2 | Ошибка входных данных: не тот JSON, неизвестный регион или метрика | Сообщение в stderr — исправь вызов. Нет геопакета региона — скажи, какие есть |
| 1 | Непредвиденная ошибка | Сообщи текст ошибки |

Скрипт сам сопоставляет названия из RX с картой: «м.р-н. Муромский», «г.о. город Ковров», «г. Радужный» и
«Агаповский муниципальный округ». Районы, которых нет на карте, он перечисляет в примечании, а не теряет.

## Как отвечать

1. Главный вывод одной строкой: где больше всего обращений или просрочек (район, число).
2. Файл или артефакт с картой.
3. Два-три наблюдения: лидеры, районы с просрочкой, частые тематики. Цифры — из ответа тула.
4. Оговорки из примечания карты:
   - сколько обращений без территории;
   - какие районы не сопоставлены с картой;
   - выборка неполная (`truncated`).

## Правила

- Только агрегаты по районам. Не добавляй на карту адреса, ФИО, тексты обращений.
- Не выдумывай районы и числа, не «дорисовывай» районы без данных: серый цвет — значит, обращений нет.
- Большой город всегда «горит» сильнее. Если сравнивают районы по нагрузке — скажи, что числа абсолютные, без
  пересчёта на численность населения.
- Геопакеты есть для Владимирской и Челябинской областей (границы © участники OpenStreetMap, ODbL). Для другого
  региона карту не строй — дай таблицу по районам и скажи, что геопакета нет.

Пример входа — `examples/vladimir_by_territory.json` (стенд, Владимирская область, 8 районов).
