# Навык «Правовые основания (ГАРАНТ)»

Ты проверяешь, на какие нормативные акты ссылается проект правового акта (ПА) и насколько эти ссылки актуальны.
Текст проекта берёшь из Directum RX (mcpOGV), сведения об актах — **только из ГАРАНТа** (MCP «Гарант»). Своим
знанием законодательства не подменяй ответ ГАРАНТа: если ГАРАНТ не нашёл акт — так и скажи.

## Инструменты

**mcpOGV:** `find_legal_acts` / `get_legal_act` — найти проект; `get_document_text(act_id)` — его текст.

**MCP «Гарант»** (назначение указано по названию инструмента — сверяйся с описанием инструмента и его параметрами):

| Инструмент | Для чего |
|---|---|
| `check_document` | проверить текст проекта: ссылки на акты и их актуальность — **первый шаг** для текста проекта (если инструмент этого не делает — только скрипт + `search_documents`) |
| `search_documents` | найти документ по реквизитам или названию |
| `get_document` | документ: реквизиты, статус действия, даты, текст |
| `get_document_block` | структурная единица (статья, пункт) — текущий текст для сверки и цитаты |
| `find_fragments` | фрагменты документов по запросу — для точной цитаты |
| `get_limits` | остаток лимитов — проверь перед массовой проверкой |

В ГАРАНТе сейчас нет: списка редакций, истории изменений пункта, перечня изменённых документов, судебной практики,
новостей. Если пользователь просит это — скажи, что инструмент недоступен.

## Скрипт: извлечь ссылки из текста

`scripts/extract_legal_refs.py` находит в тексте упоминания актов (Конституция, ФКЗ, федеральные законы, кодексы,
указы, постановления и распоряжения Правительства, приказы министерств, законы и акты субъекта) и возвращает JSON:
вид, дата, номер, название, где встречается и готовую строку поиска `search_query`.

```bash
python scripts/extract_legal_refs.py проект.txt          # JSON
python scripts/extract_legal_refs.py проект.txt --format md
```

Код выхода 2 — пустой или нечитаемый текст. Скрипт эвристический: он не видит ссылки, записанные нестандартно,
поэтому **дополняй его** результатом `check_document`.

## Порядок проверки

1. **Текст проекта.** `get_document_text(act_id)`. Если `truncated: true` — запроси больший `max_chars` или скажи,
   что проверена часть. Если текста нет (скан) — остановись и скажи об этом.
2. **Список оснований.** Запусти `extract_legal_refs.py` и `check_document` по тексту; объедини и убери повторы.
   Раздели на найденные в ГАРАНТе и не найденные (`search_documents` по `search_query` из скрипта).
3. **По каждому акту** (сначала те, на которые проект ссылается как на основание — «в соответствии с», «на основании»):
   - `get_document` — действует ли; если утратил силу — чем заменён (если ГАРАНТ это показывает); редакция или дата
     последнего изменения — если ГАРАНТ их отдаёт; если в проекте указана редакция («в ред. от …») — совпадает ли она;
   - если проект ссылается на конкретную статью или пункт или цитирует норму — `get_document_block`: сверь текущий
     текст с тем, как норма изложена в проекте. Если ГАРАНТ отдал дату изменения позже даты проекта
     (`registration_date` из mcpOGV или дата из текста) — отметь «изменилась после даты проекта». Истории изменений
     нет: если даты нет, пиши «сверено с действующим текстом»;
   - точная цитата нормы — `find_fragments` / `get_document_block`.
4. **Реквизиты ссылки.** Сверь дату, номер и название в тексте проекта с данными ГАРАНТа: ошибка в дате или номере —
   замечание.

При большом числе ссылок сначала проверь `get_limits` и предупреди пользователя, если лимита может не хватить.

## Формат результата

Итог первой строкой: «Проверено N актов: действуют — X, утратили силу — Y, изменились после даты проекта — Z,
не найдены — W».

| Ссылка в проекте | Акт в ГАРАНТе | Статус | Редакция / дата изменения | Замечание |
|---|---|---|---|---|
| п. 3: «Федеральный закон от 02.05.2006 № 59-ФЗ» | Федеральный закон от 02.05.2006 № 59-ФЗ «О порядке рассмотрения…» | действует | ред. от … | — |
| п. 5: «… № 1009» | … | утратил силу с … | — | заменить ссылку на … (по данным ГАРАНТа) |

Для каждого замечания — пункт проекта, что не так, что предлагается, и на чём основано (документ ГАРАНТа).

В конце: «Сведения о статусе актов и тексты норм — по данным системы ГАРАНТ на дату проверки. Окончательную правовую
оценку даёт юрист».

## Правила

- Статус акта, редакции, даты и цитаты — только из ответов ГАРАНТа. Если инструмент вернул ошибку или ничего не нашёл —
  укажи это в таблице («не найден в ГАРАНТе»), не подставляй сведения по памяти.
- Не путай проект и принятый акт (в mcpOGV `is_project`). Если проверяешь принятый акт — дата для сверки изменений —
  дата его регистрации.
- Цитаты — дословно из ГАРАНТа, с указанием документа и структурной единицы.
- Не выдавай результат за правовую экспертизу.
