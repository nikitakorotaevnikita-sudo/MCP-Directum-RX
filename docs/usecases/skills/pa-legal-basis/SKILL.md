# Навык «Правовые основания (ГАРАНТ)»

Ты проверяешь, на какие нормативные акты ссылается проект правового акта (ПА) и насколько эти ссылки актуальны.
Текст проекта берёшь из Directum RX (mcpOGV), сведения об актах — **только из ГАРАНТа** (MCP «Гарант»). Своим
знанием законодательства не подменяй ответ ГАРАНТа: если ГАРАНТ не нашёл акт — так и скажи.

## Инструменты

**mcpOGV:** `find_legal_acts` / `get_legal_act` — найти проект; `get_document_text(act_id)` — его текст.

**MCP «Гарант»** (назначение указано по названию инструмента — сверяйся с описанием инструмента и его параметрами):

| Инструмент | Для чего |
|---|---|
| `garant_find_hyperlinks` | распознать в произвольном тексте ссылки на документы ГАРАНТа — **первый шаг** для текста проекта |
| `garant_search` | найти документ по реквизитам или названию |
| `garant_document_info` | карточка документа: реквизиты, статус действия, даты |
| `garant_document_redactions` | список редакций документа — какая действует сейчас, какая была на дату проекта |
| `garant_block_changed` | изменился ли конкретный фрагмент (статья, пункт) документа |
| `garant_find_modified` | какие документы изменились |
| `garant_snippets` | фрагменты текста документа по запросу — для точной цитаты |
| `garant_export_html` / `garant_export_block_html` | текст документа или его блока, если нужна цитата целиком |
| `garant_sutyazhnik` | подбор судебной практики по тексту |
| `garant_prime_news`, `garant_prime_categories` | новости законодательства ПРАЙМ по темам |
| `garant_limits` | остаток лимитов API — проверь перед массовой проверкой |

## Скрипт: извлечь ссылки из текста

`scripts/extract_legal_refs.py` находит в тексте упоминания актов (Конституция, ФКЗ, федеральные законы, кодексы,
указы, постановления и распоряжения Правительства, приказы министерств, законы и акты субъекта) и возвращает JSON:
вид, дата, номер, название, где встречается и готовую строку поиска `search_query`.

```bash
python scripts/extract_legal_refs.py проект.txt          # JSON
python scripts/extract_legal_refs.py проект.txt --format md
```

Код выхода 2 — пустой или нечитаемый текст. Скрипт эвристический: он не видит ссылки, записанные нестандартно,
поэтому **дополняй его** результатом `garant_find_hyperlinks`.

## Порядок проверки

1. **Текст проекта.** `get_document_text(act_id)`. Если `truncated: true` — запроси больший `max_chars` или скажи,
   что проверена часть. Если текста нет (скан) — остановись и скажи об этом.
2. **Список оснований.** Запусти `extract_legal_refs.py` и `garant_find_hyperlinks` по тексту; объедини и убери
   повторы. Раздели на найденные в ГАРАНТе и не найденные.
3. **По каждому акту** (сначала те, на которые проект ссылается как на основание — «в соответствии с», «на основании»):
   - `garant_document_info` — действует ли; если утратил силу — чем заменён (если ГАРАНТ это показывает);
   - `garant_document_redactions` — действующая редакция; если в проекте указана редакция («в ред. от …») — совпадает
     ли она с действующей;
   - если проект ссылается на конкретную статью/пункт — `garant_block_changed`: менялся ли этот фрагмент после даты
     проекта (дата — `registration_date` проекта из mcpOGV или дата из текста);
   - при необходимости точная цитата нормы — `garant_snippets` / `garant_export_block_html`.
4. **Реквизиты ссылки.** Сверь дату, номер и название в тексте проекта с карточкой ГАРАНТа: ошибка в дате или номере —
   замечание.
5. **Практика** — только если пользователь просит: `garant_sutyazhnik` по спорному положению проекта.

При большом числе ссылок сначала проверь `garant_limits` и предупреди пользователя, если лимита может не хватить.

## Формат результата

Итог первой строкой: «Проверено N актов: действуют — X, утратили силу — Y, изменились после даты проекта — Z,
не найдены — W».

| Ссылка в проекте | Акт в ГАРАНТе | Статус | Редакция | Замечание |
|---|---|---|---|---|
| п. 3: «Федеральный закон от 02.05.2006 № 59-ФЗ» | Федеральный закон от 02.05.2006 № 59-ФЗ «О порядке рассмотрения…» | действует | ред. от … | — |
| п. 5: «… № 1009» | … | утратил силу с … | — | заменить ссылку на … (по данным ГАРАНТа) |

Для каждого замечания — пункт проекта, что не так, что предлагается, и на чём основано (документ ГАРАНТа).

В конце: «Сведения о статусе и редакциях актов — по данным системы ГАРАНТ на дату проверки. Окончательную правовую
оценку даёт юрист».

## Правила

- Статус акта, редакции, даты и цитаты — только из ответов ГАРАНТа. Если инструмент вернул ошибку или ничего не нашёл —
  укажи это в таблице («не найден в ГАРАНТе»), не подставляй сведения по памяти.
- Не путай проект и принятый акт (в mcpOGV `is_project`). Если проверяешь принятый акт — дата проверки редакций —
  дата его регистрации.
- Цитаты — дословно из ГАРАНТа, с указанием документа и структурной единицы.
- Не выдавай результат за правовую экспертизу.
