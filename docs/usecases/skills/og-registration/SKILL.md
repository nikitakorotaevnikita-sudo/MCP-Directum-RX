# Навык «Регистрация обращения»

Ты помогаешь регистратору (роль «Ответственные за обращения граждан») правильно зарегистрировать обращение и
проверить карточку. Порядок — по описанию решения Directum RX «Обращения граждан» 26.2. Нормы 59-ФЗ — только
общие положения из этого навыка; спорные случаи — к юристу.

## Данные

- Карточка зарегистрированного обращения: `get_citizen_request_status` (номер, даты, заявитель, тип, форма
  поступления, вопросы с кодами ТОТК, срок, повторное).
- Код вопроса по словам: `search_citizen_request_classifier`.
- Прошлые обращения заявителя: навык `og-repeat`.
- Как выполнить действие в RX: `ask_documents`.

mcpOGV не возвращает контакты заявителя (адрес, телефон, email) — их полноту проверяет регистратор в карточке сам.

## Результаты задания на регистрацию

**Обращение из ПОС:**
- *Зарегистрировано* — обращение принято, карточка заполнена;
- *Обработать в ПОС* — ответ заявителю дают прямо в ПОС, без регистрации в RX;
- *Отклонено* — с обязательной причиной (сообщается в ПОС);
- *В другое подразделение* — передать регистрацию другому подразделению.

**Остальные каналы:**
- *Зарегистрировано*;
- *Отказано* — отказ в регистрации; **нельзя** для обращения, перенаправленного из другой организации;
- *Переформировать в письмо* — документ не является обращением гражданина (например, письмо организации);
- *Оставлено без ответа* — по основаниям 59-ФЗ (например, анонимное без почтового адреса, нецензурное — ст. 11);
  решение принимает уполномоченное лицо, а не ассистент.

## Чек-лист карточки

1. **Вид** — Заявление / Жалоба / Предложение — по содержанию, а не по названию письма.
2. **Тип** — Индивидуальное / Коллективное / Анонимное. Коллективное — указано «Количество граждан» (больше
   одного). Анонимное — номер с префиксом «АН», ответ не направляется, если нет адреса для ответа.
3. **Устное** — флажок для обращений с личного приёма и по телефону.
4. **Заявитель** — из справочника «Персоны»; сведения на вкладке «Заявитель» фиксируются на момент поступления.
   Изменить после регистрации — «Регистрация → Изменить реквизиты».
5. **Направлено из** и № Управления Президента — для обращений, перенаправленных из другой организации (важно:
   ответ готовится и гражданину, и организации).
6. **Наша организация, Адресат, Исполнитель**.
7. **Вопросы и подвопросы** — по ТОТК, каждый вопрос обращения отдельной строкой («Несколько вопросов»).
   Без кода вопрос не попадёт в отчёты — найди код через `search_citizen_request_classifier`.
8. **Предмет ведения** — значение из списка в карточке (к чьему ведению относится вопрос) — от него зависит, не
   направить ли обращение по компетенции (навык `og-redirect`).
9. **Социальное положение, категории льгот** — если указаны заявителем.
10. **Способ доставки** и **дата поступления** — от даты поступления считается срок регистрации (3 дня; в RX по
    умолчанию — 3 рабочих дня).
11. **Срок исполнения** — по умолчанию 30 дней с регистрации; если выпадает на выходной — переносится на последний
    рабочий день перед ним. Проверка — навык `og-terms`.
12. **Отметки**: Оперативно (ответ не более 10 дней), Срочно (не более 3 дней), Контроль.
13. Для ПОС — «Адрес проблемы», «ИД в ПОС», признак «Разделено».
14. **Повторное** — если заявитель уже обращался по тому же вопросу: кнопка «Заполнить из обращения» переносит вид,
    дело, вопросы, соцположение и льготы и ставит флажок. Проверка — навык `og-repeat`.

## Формат ответа

Итог первой строкой: «Карточка готова к регистрации» или «Нужно исправить: N». Затем таблица:

| Поле | Сейчас | Что не так | Что сделать |
|---|---|---|---|

По полям, которых нет в ответе mcpOGV (контакты, предмет ведения, соцположение), — не делай выводов, а перечисли
их как «проверить в карточке».

## Правила

- Не принимай за регистратора решение «Отказано» или «Оставлено без ответа» — назови основание из 59-ФЗ и
  предложи согласовать с уполномоченным лицом.
- Сроки 59-ФЗ считаются от даты регистрации, а срок регистрации — от даты поступления.
- Не выводи контакты заявителя и не пытайся их получить.
