# Навык «Чтение PDF»

Скрипт `scripts/extract_pdf_text.py` извлекает текст из PDF, в котором есть текстовый слой (документ создан из
Word, выгружен из системы, «Сохранить как PDF»). **Сканы он не распознаёт** — OCR в навык не входит: такие страницы
скрипт находит и прямо о них сообщает.

## Когда использовать

- Пользователь приложил PDF к чату или файл лежит в рабочей папке.
- Текст PDF нужен другому навыку: сравнение редакций (`pa-compare`), нормоконтроль (`pa-normcontrol`), проверка
  писем (`og-letters`) и т. п. — сначала извлеки текст в файл, потом передай его скрипту того навыка.
- Документ из Directum RX читай инструментом mcpOGV `get_document_text` — он сам достаёт тело документа. Этот навык —
  для файлов, которые уже есть у тебя.

## Как вызвать

```bash
python scripts/extract_pdf_text.py документ.pdf                       # текст по страницам
python scripts/extract_pdf_text.py документ.pdf --pages 1-3,7         # только нужные страницы
python scripts/extract_pdf_text.py документ.pdf --format json         # данные: страницы, метаданные, флаги
python scripts/extract_pdf_text.py документ.pdf --format md           # markdown с заголовками страниц
python scripts/extract_pdf_text.py документ.pdf --out текст.txt       # в файл (в stdout — путь к файлу)
python scripts/extract_pdf_text.py документ.pdf --layout              # сохранить расположение (таблицы, колонки)
python scripts/extract_pdf_text.py документ.pdf --password ПАРОЛЬ     # зашифрованный PDF
```

Прочие параметры: `--max-chars` (лимит символов, по умолчанию 200 000; 1000–5 000 000), `--raw` (без очистки
текста), `--no-page-headers` (без строк «=== Страница N ===»), `-` вместо пути — PDF из stdin.

Зависимость: `pip install -r requirements.txt` (pypdf ≥ 4.0, чистый Python). Сеть не нужна.

| Код выхода | Значение | Что делать |
|---|---|---|
| 0 | Успех. Текстового слоя может не быть — смотри `has_text_layer` и предупреждения | Работай с текстом; предупреждения передай пользователю |
| 2 | Плохой вход: не PDF, файл повреждён, нужен или неверен пароль, неверные `--pages` | Сообщение в stderr — исправь вызов или попроси пользователя (пароль, другой файл) |
| 1 | Непредвиденная ошибка или не установлен pypdf | Сообщи текст ошибки; при «не установлен pypdf» — установи зависимость |

## Что в результате (`--format json`)

- `pages_total`, `pages_extracted`, `pages` — по каждой странице `page`, `text`, `chars`, `has_text`
  (есть ли текст), `garbled` (похоже на «кракозябры»), `error` (страница не прочиталась — остальные извлечены);
- `has_text_layer` — есть ли текст хоть на одной странице; `pages_without_text` — страницы-сканы;
  `pages_garbled` — страницы с повреждённым слоем;
- `metadata` — `title`, `author`, `subject`, `creator`, `producer`, `created`, `modified` (что есть в файле);
- `encrypted`, `truncated`, `total_chars`, `warnings` — готовые фразы для пользователя.

Очистка текста (без `--raw`): склейка переносов «благо-/устройство» (только если следующая строка начинается со
строчной буквы — «Санкт-Петербург» не трогается), удаление мягких переносов и нулевых символов, схлопывание пробелов
и лишних пустых строк. Разбиение на строки сохраняется.

## Как отвечать пользователю

1. Если `has_text_layer = false` — сразу скажи: «В PDF нет текстового слоя (скан), текст извлечь нельзя — нужен
   файл с текстом или распознавание (OCR)». Не пересказывай содержимое по догадкам.
2. Есть `pages_without_text` или `pages_garbled` — назови эти страницы и что их текст не прочитан или ненадёжен.
3. `truncated` — скажи, какие страницы прочитаны, и дочитай остальное через `--pages`.
4. Цитаты — дословно из `text`, с номером страницы. Пересказ — только по извлечённому тексту.
5. Длинный документ: сначала `--format json --max-chars 20000` для обзора (метаданные, число страниц), затем нужные
   страницы через `--pages`.

## Правила

- Не выдумывай текст страниц, которые не извлеклись (скан, ошибка, обрезка).
- Не выводи пароль в ответе и не сохраняй его.
- Персональные данные из документа (телефоны, адреса, паспорта) не повторяй без необходимости для задачи.
- Порядок текста в сложной вёрстке (колонки, таблицы) может отличаться от визуального — при сомнении попробуй
  `--layout` и скажи пользователю о возможных искажениях.

Пример: `examples/example.pdf` (две страницы текста и страница-скан), пересобрать — `examples/make_example.py`.
